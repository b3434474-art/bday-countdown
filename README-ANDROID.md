# Birthday Countdown Android APK

This repository now includes an Android wrapper for the birthday countdown website.

## Build the APK
1. Open the repository's **Actions** tab.
2. Select **Build Android APK**.
3. Tap **Run workflow** (or wait for the workflow after a relevant push).
4. When the run finishes, open it and download the **birthday-countdown-apk** artifact.
5. Extract the ZIP and install `app-debug.apk` on your Android phone.

The app loads the countdown from a bundled local HTML file, so the main countdown works offline. The music picker lets you choose an audio file stored on your device.

This is a debug APK for personal testing, not a Play Store release.
