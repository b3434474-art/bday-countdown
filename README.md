# Birthday Countdown 🎉

A free, mobile-friendly birthday countdown website built with plain HTML, CSS and JavaScript. No build tools or paid services required.

## Publish with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**.
3. Select **main** and **/(root)**, then save.
4. Wait for GitHub Pages to publish the site.

## Features
- Live days, hours, minutes and seconds countdown to the next birthday
- Birthday age counter
- Confetti with selectable patterns, colors and intensity
- Shooting stars, rotating sparkles, screen flashes, snowfall, animated party lights and floating emojis
- Cursor/touch glitter trails and particle bursts
- Preview themes before applying; live custom accent and background colors
- Party tiles, classic, neon and compact countdown designs
- Random effect, random celebration and Ultimate Celebration Mode
- Draggable balloons, poppable bubbles, fireworks launcher and animated 3D birthday card
- Birthday milestone unlock messages and full-screen birthday celebration
- Browser notification permission prompt
- Local audio-file music player
- Stores birthday, birth year and theme locally in the browser

## Personalize
Open the page and set your birthday month/day and birth year. The sample date is November 9; change it if needed.

## Notes
- Music is selected from the device and is not uploaded.
- Browser notifications require permission and are not guaranteed to run when the site is closed.
- Settings are stored in the current browser/device and are not synced.
- Respects reduced-motion preferences for accessibility.
